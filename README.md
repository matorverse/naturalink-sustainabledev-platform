# NaturalInk - AI-Powered Sustainability Platform

A modern, responsive React application focused on sustainable development and environmental awareness. Built with cutting-edge technologies and designed with eco-friendly principles in mind.

## 🌱 Features

- **AI-Powered Tools**: Carbon footprint calculator, eco-guidance chatbot, sustainability analytics
- **Community Dashboard**: Join global environmental projects and track impact
- **Educational Resources**: AI-generated content, articles, and sustainability tips
- **Interactive Elements**: Smooth animations, responsive design, modern UI/UX
- **Real-time Features**: Live chat, project tracking, community engagement

## 🚀 Tech Stack

- **Frontend**: React 18, Vite
- **Styling**: Tailwind CSS, Framer Motion
- **Icons**: Lucide React
- **Forms**: React Hook Form
- **Animations**: Framer Motion
- **Deployment**: Vercel/Netlify ready

## 📦 Installation

1. Clone the repository:
```bash
git clone <repository-url>
cd naturalink-sustainabledev-platform
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm run dev
```

4. Open [http://localhost:3000](http://localhost:3000) in your browser.

## 🛠️ Build for Production

```bash
npm run build
```

The built files will be in the `dist` directory, ready for deployment.

## 🌍 Deployment

### Vercel (Recommended)
1. Push your code to GitHub
2. Connect your repository to Vercel
3. Deploy with zero configuration

### Netlify
1. Build the project: `npm run build`
2. Drag and drop the `dist` folder to Netlify
3. Or connect your GitHub repository for automatic deployments

### Other Platforms
The built files in the `dist` directory can be deployed to any static hosting service.
